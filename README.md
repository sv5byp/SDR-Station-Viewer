# SDR Station Viewer for Windows — by SV5BYP

**A portable Windows application for finding, saving and opening online software-defined radio (SDR) receivers.**

Browse public WebSDR, KiwiSDR and OpenWebRX stations, select a frequency and reception mode, and keep your favourite receivers together in one list.

The EXE is portable: place it in a writable folder and run it. A ZIP with the multilingual user guide is also available. Requires internet access, Windows with .NET Framework 4.x and a modern browser.

Existing users: replace the old EXE in the same folder and **keep the TXT files** containing stations and settings. From version 2.0.12 onward, the built-in updater can install a newer release after confirmation.

## Features

- Initial catalog of 44 online SDR receivers, with Greek stations first.
- Save up to **500 stations**, including address, description, frequency, mode and receiver type.
- Keep up to **100 recent frequency/mode pairs**.
- WebSDR, KiwiSDR and OpenWebRX tuning links; Unknown receiver option.
- Open receivers through Edge, Chrome or the default Windows browser.
- Enter a station address and port separately.
- Confirmation before saving or deleting stations.
- English, Greek, French, German and Dutch interface and help.
- Four color themes.
- Update checks, signed update packages, backups and preservation of personal settings.

Automatic tuning and availability depend on the remote station. The application opens online receiver pages; no local SDR dongle is required.

## Quick start

1. Select a receiver under **Saved stations**.
2. Choose frequency in MHz, mode and receiver type.
3. Click **CONNECT**.
4. To add a receiver, double-click **SDR address**, enter its address and optional port, confirm, add a description and choose **Save station**.

Use **Options → Language / Colors** for appearance and language. **Help → Instructions** opens the guide; **Help → Check for updates** checks for a newer version.

## Updates

The .bin and .sig files on release pages are for the built-in updater. Download the EXE or ZIP for manual installation. The updater's digital signature is separate from Windows executable publisher signing and is not an antivirus certification.
